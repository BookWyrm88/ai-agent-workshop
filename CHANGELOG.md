# Changelog

## v0.1.0-rainbow — 2026-11-10

First preserved Git release of the existing Rainbow Workshop.

- Shared illustrated room, independent agent identities/workstations, and rainbow customization.
- Simulated task chat, independent runtimes, pause/resume/cancel, failure/retry, and execution traces.
- Blueprint configuration, Laboratory evaluation/comparison, and the eight-lesson action-based tutorial.
- Existing browser-local persistence and export/import backup functionality.
- Added Git hygiene, privacy documentation, release hashes, audit tooling, and a GitHub Pages entry point.

Application source and the existing standalone HTML were preserved byte-for-byte. The previous internal UI label `Prototype 0.2` remains as part of that snapshot; **v0.1.0-rainbow** is the Git release name. No tutorial behavior or new application feature was implemented for this release.
